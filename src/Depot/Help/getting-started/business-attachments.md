# Business Attachments

Use the **Attachments** area on a supported business record to keep related user-supplied documents with that record.

## Available actions

Depending on your permission for the selected record, you can upload a file, download the current revision, replace file content while retaining earlier revisions, edit description/category, review revision history and retire an attachment.

## Safety and limits

- Each file is limited to 25 MiB.
- Known executable and script file types are blocked.
- MIME type is metadata and is not treated as a malware verdict.
- Depot does not execute attachment content.
- Malware scanning is an external deployment responsibility.
- Generated invoices and electronic-invoice evidence remain separate authoritative records.

## Access and history

The underlying record's view/manage permissions also protect its attachments. Attachment changes are audited. Replacing a file creates a new retained revision; retiring a file does not delete its revision evidence.
